# Demo excerpts

Three 30-second stereo 44.1 kHz PCM16 excerpts from the packaged preset/seed engine:

- `vacant-angel.wav`: spacious bells, formants and damaged distant returns.
- `phone-rave.wav`: faster hardstyle-permitted rhythm with phone coloration.
- `1616-fracture.wav`: all intervention families permitted.

Each excerpt takes seconds 10–40 of a 90-second offline arrangement, with brief start/end fades for convenient playback. Sources are original synthesis and the bundled CC0 bank. Regenerate the full arrangements with `tools/render.scd`, preset 1/2/3, ISM_SECONDS=90. The full arrangements' objective measurements are in `docs/PRESET_METRICS.json`.

These are demonstrations of the instrument, not reconstructions of existing songs. The cloud validation pass did not include subjective listening.
