# Frozen integration contracts

Each module is a loadable `.scd` file assigning functions to the global environment `~ism`. Main owns creation of `~ism`, module loading and orchestration. Call functions with `.value(...)`; no implicit receiver / method syntax. All collaborators own only their assigned files.

State keys: `root` String; `sliders` Array of 10 Floats in 0..1; `switches` Array of 10 integers 0/1; `seed` positive Integer; `running` Boolean; `scene` Symbol; `status` String; `samples` Array of manifest/path records; `buffers` Array of Buffer objects; `params` Event; `window` Window or nil. Main provides `setSlider(index,value)`, `setSwitch(index,value)`, `start()`, `stop()`, `panic()`, `reseed()`, `savePreset(path)`, `loadPreset(path)`, `export(path,seconds)`. Root/file paths must be absolute from Main, never cwd. GUI updates use `.defer`.

Composer module provides `map(sliders,switches)` -> Event and `compose(seed,sliders,switches,seconds)` -> Event `(events: Array, scenes: Array, bpm: Float, duration: Float)`. An event record is `(time: seconds absolute from 0, voice: Symbol, dur: seconds, args: Array of alternating Symbol/value, seed: Integer)`. Scene records `(time: seconds, name: Symbol, beats: Integer)`. Composer pure/deterministic; no server calls. It produces independent finite scene batches for runtime and arbitrary length for NRT. Common map keys consumed by runtime/DSP: `bpm` 110..180, `bits` 5..16, `holdRate` 2500..32000, `drive` 1..4, `wear` 0..1, `delayTime` 0.02..1.5, `delayMix` 0..0.5, `feedback` 0..0.8, `reverbMix` 0..0.45, `width` 0..1, `phone` 0/1. Add keys freely, do not rename these.

DSP module provides `defineSynths()` adds definitions via `.add` and also stores `defs` Array of SynthDefs for NRT `.asBytes`. Voice symbols: `ismKick`, `ismSnare`, `ismHat`, `ismBass`, `ismBell`, `ismPad`, `ismGhost`, `ismNoise`, `ismSampleMono`, `ismSampleStereo`. ALL voices accept controls `out` audio bus, `freq` Hz, `amp`, `pan` -1..1, `dur` seconds, `seed` Integer, plus `drive` 1..4, `tone` 0..1, `reverse` 0/1, `bend` semitones. Sample voices additionally `buf`, `rate`, `start` normalized 0..1. Every voice frees itself, stereo output (Pan2 for mono). DSP effect `ismFX` reads bus `in`, writes stereo bus `out`, accepts map controls `bits`, `holdRate`, `drive`, `wear`, `delayTime`, `delayMix`, `feedback`, `reverbMix`, `width`, `phone`. `ismMaster` reads `in`, writes hardware0, controls `gain` default0.72, `gate` default1 with short fade; final limiter+DC blocking. Sources->FX->master ordered by groups. Runtime adds correct `out`, `seed`, `dur` before event.args.

GUI module provides `makeGUI()` -> Window. Exactly 10 Slider widgets, exactly10 two-state Button switches; any transport buttons are single-state momentary. `sliderViews`, `switchViews` stored for tests. `refreshGUI()` updates widgets/status safely on AppClock. GUI calls main callbacks above. Use ASCII stable indices, named labels from plan. Main provides `presetNames` and `applyPreset(name)`; GUI can have a PopUpMenu for presets (does not count as a slider/switch). GUI no boot logic; main boots server and can construct GUI before boot completes. No asset dependency required for GUI drawing.

Render module owned by lead provides `render(seconds,path,done)` -> NRT Score, uses definitions and composed event records. Main runtime owns node groups, bus allocation, lifecycle and realtime scheduling. Assets agent owns `assets/optional`, `assets/LICENSES.json`, `tools/fetch_assets.py`, `docs/REFERENCE_NOTES.md`; provide WAV files <=50MB, mono/stereo at44100/48000, licensed download manifest, no copied songs. Asset parsing can be simplified to scan WAVs rather than JSON at runtime.

SC language pitfalls: all `var` declarations at beginning of function/block; use `if(condition,{},{})` or `condition.if`; do not write JavaScript/Python syntax. Events/functions stored in `~ism` must use `.value` calls. GUI tests cannot prove audible realtime. Seed server noise via `RandSeed.ir(1, seed)` per voice. Reference track audition unavailable unless actually performed; document uncertainty.
